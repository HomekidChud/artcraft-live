How your key and costs work

This page is a public static site: the key stays in this tab's memory only, is never saved to storage, and is sent directly to Anthropic with the browser-access header. Use a restricted, low-limit key you can revoke. API use costs money on your key — every agent in an agent team is a separate paid call.

Browser — fetch a page's text

Reads a public page's text from your browser. Many sites block browser fetches; that is reported honestly. This is not a controllable browser — no clicking, scrolling or logging in.

Claude is off until you connect.
Connect an Anthropic API key, then use the quick actions on your selection, chat about the open document, share a URL to read its text, or ask for an agent team — for example “use 4 agents to draft release notes from this document”. Nothing is sent anywhere while disconnected.
