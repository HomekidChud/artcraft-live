# Original demo dialogue

`last-signal-voice.mp3` is AI-generated speech for VideoCraft's original
**The Last Signal** demonstration. Voice: Gemini Aoede.

Script:

> We thought the city had gone quiet. Then, just before dawn... the signal came back.

The app bundles this small source file so the demo works without generation
credentials. Loading the demo embeds the audio and its amplitude envelope in
the saved project. No claim is made that the voice is a real performer or that
the amplitude-driven mouth animation is phoneme-accurate lip sync.
