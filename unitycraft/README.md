# UnityCraft

A browser reconstruction of the **Unity Hub** launcher and a **Unity Editor**-style 3D workspace — the UnityCraft take on "Unity in the browser", with a Unity-inspired engine layer (rigidbody physics, a shader system, and the core component set of a game engine: colliders, audio, particles and animation).

- **Hub** — dark launcher with Projects / Installs / Learn / Community / Preferences, a New Project flow with templates and editor-version selection, project cards with version chips and favorites, and a splash screen with a spinning-progress ring.
- **Editor** — Three.js scene view with grid, gizmos and an axis widget; Hierarchy with live search; Inspector (Transform / Mesh Renderer with a 7-preset shader system / Rigidbody / Collider / Audio Source / Particle System / Animator / Light / Camera); GameObject creation menu with ten 3D primitives; grid snapping (0.5 translate, 15° rotate, 0.25 scale, Ctrl to invert); script components (Spin, Bob) with **Play mode** that animates objects and restores scene state on Stop; play/pause/step; undo/redo; scene save/load (localStorage with in-memory fallback); console with severity filters and clear; Game view rendered from the scene's Main Camera.
- **Physics engine** — Unity-style rigidbody simulation at a fixed 1/60 s timestep: mass, linear damping, gravity toggle, kinematic mode, per-axis freeze constraints, box + sphere colliders, triggers (OnTriggerEnter/OnCollisionEnter events in the Console), per-object physics materials (bounciness + friction, averaged on contact — Unity's default combine), and sleeping bodies.
- **Shaders** — a serializable material config driving Standard (Lit PBR), Unlit, Toon (ramp), Hologram (fresnel + animated scanlines, custom GLSL), Water (animated vertex waves, custom GLSL), Dissolve (animated noise burn-away, custom GLSL) and Wireframe presets, all editable in the Inspector and animated by a simulation clock that freezes on Pause.
- **Engine components** — Audio Source (WebAudio-generated tones: volume/pitch/loop/play-on-awake), Particle System (THREE.Points emitter: rate/lifetime/speed/size/color/gravity/cone, previewed in edit mode), Animator (keyframe tracks for position/rotation/scale with linear interpolation, loop and speed), and a Scene Settings window (skybox, fog, ambient light, gravity) persisted with the scene.

## Provenance

This is a clean-room reconstruction — no Unity Technologies code, assets, or binaries are redistributed. The Hub logo/splash artwork and all UI code in this module are original. **"1:1" is the design goal, not a claim**: every behavior below is labeled with how it is supported (source-assisted, binary-evidence-assisted, or documentation-based), and the real Editor's runtime behavior was never execution-verified against this reconstruction.

Not implemented: Hierarchy parenting (Create Empty Parent does not actually parent objects — see its ledger row), multi-object prefabs (only single-object prefabs are supported), asset import, horizontal physics for the PlayerController (collision is vertical/ground only; Rigidbody bodies do collide), rotation dynamics (dynamic bodies keep their orientation — no angular velocity), continuous collision detection (fast bodies can tunnel through thin colliders at extreme speeds), capsule/mesh collider shapes, imported audio clips (tones are generated), C# compilation (script components are built-in JS behaviors), Preferences. Scripts are skipped on dynamic (non-kinematic) Rigidbodies — physics owns their transform. Custom GLSL shaders cast shadows but do not receive them. Research notes mapping every new system to its Unity source live in [RESEARCH.md](RESEARCH.md). The real Editor's runtime behavior was not execution-verified (static analysis only) — parity with Unity documentation is the working standard.

## Run

Static site — serve the repo root (`python -m http.server`) or open via GitHub Pages, then launch the UnityCraft card. Requires an up-to-date desktop browser (WebGL + ES modules).
