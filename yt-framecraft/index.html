YouTube → frame-perfect MP4 (CLI)

# grab any YouTube video as a frame-perfect, AI-ready MP4 python3 yt-framecraft https://www.youtube.com/watch?v=VIDEO_ID # force 24 fps, cap the long edge at 1280px for vision models python3 yt-framecraft VIDEO_ID --fps 24 --scale 1280 # also dump every frame as PNG + 5x5 contact sheets python3 yt-framecraft VIDEO_ID --frames png_out --grid sheets # convert a local file instead python3 yt-framecraft --file lecture.mp4 -o lecture_ai.mp4

The CLI produces a constant-frame-rate H.264 MP4 with keyframes every second, burned-in frame numbers and timestamps, and a .json sidecar (fps, frame count, duration) so AI pipelines can reference frames exactly. Requires yt-dlp and ffmpeg. Only download videos you have the rights to.

Set the fps field above to match your encode (the CLI keeps the source rate by default) — the inspector rounds to the nearest frame, and the burned-in numbers let you verify alignment.
