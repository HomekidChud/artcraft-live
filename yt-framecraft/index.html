CLI (fallback + local files)

# same frame-perfect output, on your machine python3 yt-framecraft https://www.youtube.com/watch?v=VIDEO_ID # force 24 fps, cap the long edge at 1280px, dump PNG frames + contact sheets python3 yt-framecraft VIDEO_ID --fps 24 --scale 1280 --frames png_out --grid sheets # convert a local file python3 yt-framecraft --file lecture.mp4 -o lecture_ai.mp4

The CLI writes a .json sidecar next to the MP4 (fps, frame count, duration) so AI pipelines can reference frames exactly. Requires yt-dlp and ffmpeg. Only download videos you have the rights to.

In-browser conversion pulls the video through public Piped mirrors — if every mirror is blocked, use the CLI or drop a file. First conversion downloads the ~30 MB encoder engine once; encoding is single-threaded, so keep clips short.
